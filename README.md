# Calculator App

A sleek and lightweight mini calculator built with Python and Flet.

## ✨ Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal support
- Percentage and sign toggle
- Clear and backspace controls
- Keyboard support for quick calculations
- Modern dark-themed UI

## 🚀 Run the app

if you are using Flet directly:

```bash
flet run main.py
```

## 📌 Project Goal

This project is designed to help practice Python GUI development with Flet while building a useful everyday tool.

## 🛠️ Tech Stack

- Python
- Flet

## 💡 Example

```text
Input: 12 + 8
Output: 20
```
